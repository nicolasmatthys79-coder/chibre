Comment ça marche ?

Commencer une partie

Inscrivez les noms des joueurs dans les équipes « Nous » et « Eux », puis choisissez le mode de jeu. La feuille permet de saisir jusqu’à 12 donnes.

  • 1000 · normal : les points des donnes et des annonces sont comptés une fois. L’objectif est de 1000 points.
  • 1500 · pique double : dans cette application, tous les points des donnes et des annonces sont doublés. L’objectif est de 1500 points.

Inscrire les points d’une donne

Saisissez les points d’une seule équipe, puis validez ou quittez la case. L’autre équipe est calculée automatiquement : 157 moins les points saisis. Par exemple, si Nous marque 100, Eux reçoit 57.

Vous pouvez inscrire un nombre entier de 2 à 155, ou 257 pour un match. Chaque équipe doit recevoir au moins 2 points dans une donne normale. Les saisies de 0, 1 et de 156 à 256 ne sont pas acceptées ; le 0 est réservé au score calculé automatiquement pour l’équipe qui subit un match.

Pour corriger une donne, modifiez l’une des deux cases. Pour l’effacer, videz une case et validez : les deux scores de cette donne seront effacés.

Compter un match

Une saisie de 257 donne 0 à l’autre équipe et ajoute automatiquement un match au compteur de l’équipe qui l’a fait. Si une équipe remporte tous les points de la donne, c’est un match : inscrivez 257, et non 157.

Vous pouvez aussi utiliser le bouton + de la ligne « Match » : il inscrit 257 sur la prochaine donne libre. Le bouton − retire le dernier match de cette équipe et libère sa donne.

Le compteur suit les donnes : corriger ou effacer un 257 ajuste automatiquement le nombre de match. Les 257 points sont déjà inclus dans les points des donnes ; ils ne sont pas ajoutés une seconde fois aux annonces.

Ajouter les annonces

Dans « Annonces Nous » ou « Annonces Eux », utilisez + et − pour compter les annonces de 20, 50, 100, 150 ou 200 points. Le total des annonces s’ajoute aux points des donnes.

Voir les totaux et terminer une partie

Les totaux se mettent à jour automatiquement. La première équipe qui atteint ou dépasse l’objectif (1000 ou 1500 points selon le mode) gagne : un message annonce sa victoire. Le gagnant est conservé pour la partie, même si d’autres points sont ensuite ajoutés. Il n’y a pas d’égalité.

Pour enregistrer la partie dans l’historique et recommencer, appuyez sur « Nouvelle partie », puis confirmez. Une partie contenant des scores ou des annonces est enregistrée, même si l’objectif n’a pas encore été atteint. Une partie entièrement vide n’est pas enregistrée. Les noms des équipes et le mode choisi sont conservés.

Consulter l’historique

Le bouton « Historique » affiche les parties enregistrées avec leur date, les équipes, leurs scores et le mode de jeu. Sous chaque équipe, vous retrouvez les points d’annonces et le nombre de match.

Pour les anciennes parties dont le nombre de match n’avait pas été enregistré, un tiret « — » apparaît. Le gagnant affiché dans l’historique est la première équipe qui a atteint l’objectif. Si vous arrêtez une partie avant l’objectif, aucun gagnant n’est désigné. Pour les anciennes parties, si le premier gagnant n’avait pas été enregistré, l’historique indique « Gagnant non enregistré ».

L’icône de partage sous la croix permet de partager le résumé de cette partie (scores, annonces et nombre de match). Si le partage n’est pas disponible, le résumé peut être copié. La croix d’une partie permet de la supprimer après confirmation. « Effacer historique » supprime toutes les parties enregistrées après confirmation.

Sauvegarde, partage et impression

La partie en cours et l’historique sont sauvegardés dans le navigateur de cet appareil. Ils ne sont pas synchronisés avec d’autres appareils. Effacer les données du navigateur peut supprimer ces sauvegardes.

Le bouton de partage à côté du titre partage l’adresse de l’application, ou copie le lien si cette fonction est disponible. Il ne partage pas vos parties enregistrées.

« Imprimer » ouvre l’impression de la feuille de score. Dans l’historique, « Imprimer historique » permet d’imprimer les parties affichées.

Installer l’application sur le téléphone

Ouvrez d’abord la page du jeu Chibre Suisse à son adresse sur le site, avec une connexion Internet. L’installation se fait depuis cette page, et non depuis cette page d’aide.

Sur Android : ouvrez le jeu dans Chrome, appuyez sur le menu ⋮, puis sur « Ajouter à l’écran d’accueil » et « Installer » si cette option apparaît. Confirmez l’installation. Selon votre version de Chrome, le menu peut aussi proposer directement « Installer l’application ».

Sur iPhone : ouvrez le jeu dans Safari, appuyez sur le bouton Partager (le carré avec une flèche vers le haut), puis choisissez « Sur l’écran d’accueil ». Si l’option « Ouvrir comme app web » apparaît, activez-la, puis appuyez sur « Ajouter ».

L’icône Chibre Suisse apparaît sur l’écran d’accueil : touchez-la pour lancer le jeu comme une application. Ouvrez-la une première fois avec une connexion Internet afin de charger les fichiers nécessaires au fonctionnement hors connexion.

Les intitulés des menus peuvent varier selon la version de votre téléphone. Retrouvez les étapes officielles dans les aides Google Chrome et Apple pour iPhone.
